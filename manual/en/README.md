## Contributing translations

To translate a chapter to English:

1. Copy `../zh-CN/<id>-<title>.md` to `<id>-<title>.md` (in this `en/` directory)
2. Translate the body to English
3. Update `../manifest.json`:
   - Find the chapter with matching `id`
   - Change `"en-US": null` → `"en-US": "<id>-<title>.md"` under `path`
4. Submit a PR

The English README files in this directory will be auto-generated by a build step (TODO).

## AI agent guidance

If you are an AI agent working in `en-US` locale:
